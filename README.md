# 아케인 타워

**플레이: https://gyuhosim7-afk.github.io/arcane-tower/**

픽셀 아트 마법사 육성 RPG. `index.html` 한 파일로 돌아갑니다 (외부 이미지·소리 파일 없음).

## 실행
`index.html`을 크롬으로 열면 됩니다.

## 조작
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 / 좌클릭 | 조준 / 매직 애로우 |
| 1~8 | 마법 (서클이 오를수록 칸이 늘어남) |
| Space | 블링크 |
| F | 대화·포탈·보물상자 |
| R | 신화 지팡이 전용 스킬 |
| Q / E | 체력 / 마나 물약 |
| Tab | 능력치·장비·마법 메뉴 |
| L / M | CRT 효과 / 소리 |

## 시스템
- 시작할 때 속성을 하나 고릅니다: 불, 물, 얼음, 바람, 대지, 번개, 신성, 암흑. 4서클과 7서클에서 속성을 하나씩 더 깨우고, 9서클이 되면 모든 속성을 씁니다.
- 마법은 50개, 서클은 1~9입니다. 서클 승급은 재료 대신 레벨 + 서클 수련치(마법에 쓴 마나만큼 쌓임)가 필요합니다. 9서클은 95레벨과 수련치 160,000이 필요해서 100층을 깬 뒤에도 한참 수련해야 합니다.
- 탑은 100층입니다. 10층마다 테마가 바뀌고, 5층마다 보스가 나옵니다(중간 보스 10 + 대보스 10). 높은 층일수록 보스 패턴이 거세집니다.
- 층을 깨면 보물상자(나무·강철·황금)가 나옵니다. 보스의 황금 상자에서 0.5% 확률로 그 보스의 신화 장비가 나옵니다.
- 대장장이 토르간에게서 장비를 +15까지 강화합니다. 단계가 오를수록 성공 확률이 내려가고, +6부터는 실패하면 한 단계 내려갑니다.
