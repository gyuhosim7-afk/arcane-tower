# 아케인 타워

**플레이: https://gyuhosim7-afk.github.io/arcane-tower/**

픽셀 아트 마법사 육성 RPG. 게임 코드는 `index.html`에 있고, 공격 이펙트 스프라이트는 `assets/pixelfx/`에서 불러옵니다.

## 효과 에셋 출처
속성 공격 이펙트는 [Pixelfx](https://patch-gg.github.io/pixelfx/)의 Patch 및 Hugo Duprez 제작 에셋을 사용합니다. MIT 라이선스 조건에 따라 원본 프레임에서 투명 스프라이트시트를 생성하고 픽셀 품질을 유지하며 축소했습니다. 출처: [GitHub 저장소](https://github.com/patch-gg/pixelfx). 라이선스 전문은 `assets/pixelfx/LICENSE`에 포함되어 있습니다.

## 실행
`index.html`을 크롬으로 열면 됩니다.

## 조작
| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 / 좌클릭 | 조준 / 매직 애로우 |
| 1~8 | 마법 (서클이 오를수록 칸이 늘어남) |
| Space | 순간이동 (이동하는 방향, 멈춰 있으면 바라보는 방향) |
| F | 대화·포탈·보물상자 / 용화 중 심연의 포효 |
| R | 신화 지팡이 전용 스킬 |
| G | 드래곤 로드: 용의 숨결 / 분노 100에서 용화 |
| Q / E | 체력 / 마나 물약 |
| Tab | 능력치·장비·마법 메뉴 |
| L / M | CRT 효과 / 소리 |

## 시스템
- 시작할 때 속성을 하나 고릅니다: 불, 물, 얼음, 바람, 대지, 번개, 신성, 암흑. 4서클과 7서클에서 속성을 하나씩 더 깨우고, 9서클이 되면 모든 속성을 씁니다.
- 마법은 76개, 서클은 1~9입니다. 속성마다 1~8서클에 빈칸 없이 마법이 있고, 물을 뺀 일곱 속성은 9서클 전용 마법도 있습니다. 서클 승급은 재료 대신 레벨 + 서클 수련치(마법에 쓴 마나만큼 쌓임)가 필요합니다. 9서클은 95레벨과 수련치 160,000이 필요해서 100층을 깬 뒤에도 한참 수련해야 합니다.
- 탑은 100층입니다. 층마다 방 구조가 바뀝니다(기둥 홀, 십자방, 섬, 칸막이 방, 강과 다리, 잔해, 팔각방, 벽 조각). 테마마다 바닥 무늬와 웅덩이(물·용암·얼음·모래·심연), 장식물이 다릅니다. 10층마다 테마가 바뀌고, 5층마다 보스가 나옵니다(중간 보스 10 + 대보스 10). 높은 층일수록 보스 패턴이 거세집니다. 정예는 일반 층에서 15% 확률로 나옵니다. 100층 마왕은 졸개 없이 세 단계로 강해지며 9서클이 되어야 상대할 만합니다.
- 보스 20마리는 각자 전용 패턴이 있습니다(쥐떼 질주, 석화의 눈, 뇌전 결계, 검의 감옥, 죽음의 낙인, 폭풍의 눈, 창조와 파괴 등). 높은 층 보스일수록 패턴 수가 많고, 30층부터는 패턴 두 개를 이어서 씁니다.
- 보스 15~100층은 두 번째 전용 기믹도 씁니다: 중독·화상·출혈·침묵·저주·실명·빙결 디버프, 분신, 공간 봉쇄(원 밖은 피해), 차원 붕괴(빨아들이는 틈), 생명 흡수(멀리 떨어지면 끊김).
- 전투 모드: [수동/자동] 버튼(또는 T키). 자동이면 기술은 알아서 가장 가까운 적에게 씁니다. 방어 마법도 자동입니다: 쉴드는 적·탄막·디버프가 있으면 막이 없을 때 바로, 힐은 체력 70% 아래(그레이트 힐은 45% 아래), 무적기(샤이닝 샤워·리절렉션)는 체력 40% 아래일 때 씁니다. 기본 공격은 직접 쏘지만 조준은 가장 가까운 적으로 자동입니다. 수동이면 자동 조준이 없습니다. 태블릿은 화면 왼쪽 조이스틱으로 움직이고, 오른쪽 조이스틱(조준 스틱)을 미는 방향으로 조준하며 쏩니다. 자동 모드에서도 조준 스틱을 쓰면 그 방향이 우선입니다.
- 장비 그림: 지팡이는 등급마다 생김새가 다르고(일반 초승달, 고급 덩굴, 희귀 날개, 영웅 보랏빛 소용돌이, 전설 황금 눈, 전설 황금 눈까지), 로브는 후드 망토, 반지는 보석 반지 모양입니다. 신화 장비 10개는 모두 고유한 생김새입니다.
- 층을 깨면 보물상자(나무·강철·황금)가 나옵니다. 신화 장비는 보스 20마리마다 1개씩, 모두 20개이고 그 보스의 상자에서만 1% 확률로 나옵니다. 일반 장비는 전설 등급까지만 나오며, 신화 등급은 고유 생김새의 보스 신화뿐입니다. 신화는 +0이어도 같은 레벨 전설 +15강보다 기본 능력치가 높고, 어려운(높은 층) 보스의 신화일수록 더 강합니다(5층 ×7.0 → 100층 ×8.9, 전설 +15는 ×6.6, 옵션도 ×1.15 → ×1.6). 신화를 끼고 보스에 가면 보스가 강해지고, 높은 층 신화일수록 더 많이 강해집니다.
- 대장장이 토르간에게서 장비를 +15까지 강화합니다. 단계가 오를수록 성공 확률이 내려가고, +6부터는 실패하면 한 단계 내려가며, +10부터는 장비가 부서질 수 있습니다. 파괴 방지권을 켜 두면 부서질 때 방지권이 대신 깨집니다.
- 로브·반지·지팡이는 종류마다 5가지 모양이 있고 등급마다 색이 다릅니다. 든 지팡이와 입은 로브 등급이 캐릭터에 보입니다.
- 제단에서 정체불명의 재료는 이름·설명·등급이 모두 `???`로 표시됩니다.
- 드래곤 로드는 모든 피해 +30%, 적 체력 비례 용술(보스는 타격당 최대 체력의 최대 6%), 최대 체력 +30%, 화상·중독·출혈 면역, 받는 피해 -15%를 얻습니다. 체력이 50% 아래로 떨어지면 60초마다 한 번 3초간 피해를 50% 줄입니다. 피해를 주거나 받으면 분노가 차며, G로 3초간 부채꼴 화염 브레스를 사용하고 분노 100에서는 G로 15초간 심연룡으로 변신합니다. 변신 중에는 크기가 2배가 되고 비행해 장애물과 바닥 장판을 무시하며, 용술이 날개 돌풍·꼬리 강타로 강화됩니다. F는 화면의 적을 2초 기절시키고 보스 패턴 1회를 끊으며, 변신당 한 번 사용할 수 있습니다. 드래곤 로드는 다른 속성 마법과 신화 지팡이 전용 스킬을 사용할 수 없고, 용술 3종만 단축 슬롯에 장착합니다.
- 현상금 의뢰의 경험치 보상은 기존 대비 80% 감소했습니다. 레벨업 포인트는 기존처럼 항상 +3입니다. 투자한 INT·VIT·CRIT·WIS의 점당 효과는 Lv.60부터 서서히 상승해 Lv.89에 최대 120%가 되고, Lv.90 이후 낮아져 Lv.120부터 기본 100%로 유지됩니다. 장비의 능력치 옵션은 이 배율의 영향을 받지 않습니다.
- 캐릭터별 칭호는 저장 코드에 포함되며, 플레이어 이름표와 능력치 화면에 표시됩니다.
